# student-hack

Mini Universe Builder is an interactive 3D physics sandbox where users can create and explore their own miniature universes directly in the browser. Built with Next.js for a responsive interface and Three.js for real-time 3D rendering, the project simulates gravitational interactions between user-placed planets, allowing for emergent orbital systems, chaotic motion, and cosmic collisions.

Users can click to spawn planets with random mass, size, and initial velocity, then observe how gravity shapes their motion over time. When planets collide, they trigger explosion effects, which is very cool! Do have some fun with the project.
